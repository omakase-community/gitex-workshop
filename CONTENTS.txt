WORKSHOP V5 - FILE DIRECTORY

Open this entire folder as a local Codex project and send: Start the workshop.
START-HERE.pdf and START-HERE.txt explain the seven workflows.
AGENTS.md routes a start request to the workshop guide.
.agents/skills is the working copy. Skills/ and Examples/ are matching reading copies.
Eight skills include the menu/router and seven workflows; nine example inputs are fictional.
Connecting an account is separate from installing a plugin or approving external changes.
No credentials or participant data are included.
